# Mining Insights from Customer Feedback

An NLP and text-analytics pipeline that extracts insights from customer support tickets. The project compares text representations, clustering methods, topic models and sentiment analysers to find out what customers are complaining about, how those issues group together, and how customers feel about them.

The analysis uses the [Customer Support Ticket Dataset](https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset) (around 8,500 tickets) from Kaggle.

## What the project covers

| Stage | Description | Notebook |
|-------|-------------|----------|
| Exploratory data analysis | Ticket length, ticket types, priorities, channels and vocabulary | `01_eda/` |
| Text preprocessing | Lower-casing, contraction expansion, noise removal, tokenisation, stop-word removal and POS-aware lemmatisation | `03_text_representation/` |
| Text representation | Bag-of-Words, TF-IDF, Skip-gram (Word2Vec) and Sentence-BERT embeddings | `04_pipeline/EmbeddingsVisualization.ipynb` |
| Clustering | K-Means and hierarchical agglomerative clustering, with LSA / PCA / UMAP dimensionality reduction | `02_clustering/` |
| Topic modelling | LDA (BoW and TF-IDF) compared with BERTopic | `04_pipeline/TopicModelling.ipynb` |
| Sentiment analysis | VADER compared with TextBlob | `04_pipeline/SentimentAnalysis.ipynb` |
| Evaluation | Cluster quality (silhouette score), stability, topic coherence and interpretability | `05_evaluation/` |

## Tech stack

Python · pandas · scikit-learn · NLTK · Gensim · Sentence-Transformers · BERTopic · VADER · TextBlob · UMAP · Matplotlib · Seaborn · Plotly · Jupyter

## Getting started

### 1. Set up the environment

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Get the data

The dataset is downloaded with `kagglehub`. Save it as:

```
data/raw/customer_support_tickets.csv
```

### 3. Run the notebooks

The EDA notebooks (`01_eda/`) run on their own. For the main pipeline, run in this order:

1. `03_text_representation/Text-Preprocessing.ipynb` – cleans the text and builds the BoW, TF-IDF, Skip-gram and SBERT representations
2. `02_clustering/ClusterningAnalysis.ipynb` – clustering sweep; saves the cluster labels
3. `04_pipeline/` – embeddings visualisation, sentiment analysis and topic modelling; saves the trained models
4. `05_evaluation/Evaluation.ipynb` – loads the saved models and labels for evaluation

`02_clustering/LSA_PCA_UMAP.ipynb` is an exploratory notebook (LSA, PCA and UMAP dimensionality reduction before clustering) written against an earlier version of the clustering code. Its saved outputs show the results, but it does not run against the current pipeline without changes.

> **Note:** the first run downloads the pre-trained `word2vec-google-news-300` model (about 1.6 GB) through Gensim, so preprocessing takes a while the first time.
